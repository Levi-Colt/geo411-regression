# geo411-regression
Regression analysis using R

Overview: This assignment was an exercise in creating regression models and performing transformations on these models using SAT data and mosquito population data.

Methods: R, Linear Regression, Linear Transformation

Key Findings: The first regression model showed that SAT scores were a good predictor of gpa. The second regression model showed that increases in breeding sites lead to increases and mosquito populations. However, by performing transformations on the second data set, the specific relationship between increases and breeding sites and increases in mosquito population were further clarified. 

Tools: RStudio

Reflection: Performing linear Transformations or log Transformations on data sets can sometimes make the data sets more suitable for statistical analysis.
